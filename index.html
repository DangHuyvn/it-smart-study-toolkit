THE THREE METHODS

Study with a strategy

Use each tool on its own, or combine all three into a repeatable learning routine.

▦

Forgetting Curve → Spaced Revision

The forgetting curve describes how memory can fade over time. Spaced revision is a practical strategy: revisit material across multiple sessions and use retrieval practice to check what you remember.

◷

Pomodoro → Focus & Breaks

Work on one clearly defined task during a focus block, then take a short break. Adjust the duration to your task, attention, and needs; Pomodoro is a flexible strategy, not a guaranteed burnout treatment.

✧

Active Recall → Retrieve, Don't Just Reread

Try to answer a question, explain a concept, or write code from memory before checking notes. Review mistakes to identify what needs more practice.

↻

Put them together

Choose a topic → focus on it → retrieve it from memory → schedule another review → adjust based on what you can recall.
